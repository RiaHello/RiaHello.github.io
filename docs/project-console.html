类型
普通前端函数 / Vue 组件
输入
home / resume / contact 哈希或导航事件
输出
互斥页面与转场状态
展开算法、参数与异常源码已核对 · 指纹一致

处理对象：页面哈希与互斥视图

  1. 读取 location.hash；contact / resume 之外的值归为 home。
  2. 站内导航先 pushState 写入目标哈希，再取消旧转场 RAF、切页与完成计时器。
  3. 普通模式所有页面保留随机扫描转场；hashchange立即同步视图。首页挂载1200ms后准备隐藏联系组件；提前点击联系入口时，在转场开始就准备媒体。
  4. App 卸载取消计时器和 RAF，移除 hashchange；PageTransition 卸载移除 resize 并释放 ctx、粒子。

条件分支

  • prefers-reduced-motion 时直接切页。
  • 快速重复导航只保留最后一次切换；历史返回/前进通过 hashchange 同步。

结果选择：最后一次导航目标生效；同一时刻仅显示一个页面，联系组件后台准备并持续保留。

  • 未知 hash 回退首页；无服务端请求。

连续朝向与视频定位

源码已核对 · 指纹一致

把固定正脸区与指针在两侧的距离映射为连续角度

类型
普通前端函数 / Vue 组件
输入
PointerEvent / 媒体事件
输出
HTMLVideoElement.currentTime
展开算法、参数与异常源码已核对 · 指纹一致

处理对象：目标朝向与对应视频时间

  1. prepare-contact-gaze.sh将原片24fps连续帧8～30倒序（保留自然眨眼），接右侧帧65～78；OBMC插值60fps，全I帧编码。保留连续原生回正动作，避免跨姿态拼接带来的重影；原始视频保留。
  2. loadedmetadata获取有限duration，定位正面120/60秒；首次定位完成后才显示video，保持paused、muted、playsinline，无autoplay。
  3. 读取window.innerWidth，frontZone={left:0.45,right:0.5}；以视口比例确定边界，不再计算眼睛位置。
  4. lookAtPointer在45%～50%内设目标0，区外按距该侧边界的剩余距离归一化。反向即回正，35ms平滑，收敛后同目标直接返回。
  5. timeForGaze分别线性映射左10/60→正120/60→右190/60秒；0处连续。
  6. setTime量化到60fps帧格并加0.0001秒，限制0…duration-1/60；半帧以内不重复seek，只保留一个在途seek，seeked接最新目标，无额外seek RAF。
