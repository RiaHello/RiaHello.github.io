# RIA 肖像联系页

status: Implemented — 用户已委托按参考实现，视觉结果待用户查看。

范围：仅联系页，依据 PRD 的 REQ-CONTACT / AC-CONTACT-1～5。参考用户粘贴的 Mainframe 提示词及本人提供的 4 秒毛毡肖像视频。基准 1440×900；适配 320px 以上触屏及桌面。

## 设计目标与取舍

让访客先认识石耳，再自然开始对话。采用全屏暖色肖像、深炭色阅读区、白色圆角按钮和少量原站荧光绿。保留原站 RIA 标识与真实身份；不照搬机构名称、业务文案或字体外链，不新增字体服务依赖。使用现有 Inter / SF Pro Display / PingFang SC / system-ui 回退。

桌面人物位于右侧且头部完整，左侧文字避开五官。用连续渐变连接暖色视频与深色阅读区，避免卡片头像、霓虹框、内容面板。手机人物在上，介绍与操作在下；矮屏允许页内纵向滚动。原片水印不专门抹除。

## 视觉规则

- 阅读区 #171916；正文 #f5f3ed，次要文字 #d4d2cb；品牌点缀 #b7ff3b；视频保留暖米色。
- 导航 13–14px；移除正文身份眉题；主标题桌面 clamp(64px, 7vw, 108px)，手机 48–56px；正文 15–18px、行高 1.7；按钮 13–14px、最小高 44px。
- 桌面边距 48–72px、主要内容宽 520px。手机边距 24px（320px 时 20px）。胶囊按钮圆角 999px、间距 10px。邮箱可换行不溢出。
- 引导性装饰英文可轻微模糊，仅作装饰且 aria-hidden；主要标题和说明保持清晰。
- 顶栏高约 88px；视频底层、渐变遮罩、内容、导航和菜单依次叠放。页面无默认自动播放。逐字效果与操作区分别计时，按钮不等待打字完成。
- focus-visible 使用清晰荧光绿外框， hover 不依赖颜色单一反馈。prefers-reduced-motion 关闭逐字、光标闪烁和指针跟随。

## 联系页布局与状态

顶部：RIA 标记、首页 / 关于我 / 联系我；手机折叠菜单。正文：主标题「Let's talk.」及中文介绍；上方灰雾手写背景英文「Our story / is just beginning.」占据更大篇幅。三个主要胶囊行动：聊聊项目（跳转关于我）、加个微信（复制）、看看 GitHub。移除重复的关于我胶囊按钮，顶栏与手机菜单中的关于我导航保留。邮箱独立描边胶囊可复制。底部仅保留桌面页码，移除肖像朝向滑块，不显示转头提示或对话标语。

首帧海报立即显示；元数据就绪后才能 seek。复制中禁止误报，成功呈现「已复制」，失败显示实际文字和手动复制提示。移动菜单打开时焦点进入菜单，关闭返回触发按钮，Escape 可关闭。不会用“操作成功”弹窗代替真实跳转或复制。
